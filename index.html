DukRead 讀書鴨鴨 GitHub

讀英文 PDF：查單字、做筆記、中英對照。

免費的 Windows PDF 閱讀器。原版頁面照看，點一個字就查，選一段就能畫線、寫筆記、翻成中文。

下載 Windows 版
Windows 10 / 11（64 位元）· 免費 · 更新記錄

能做什麼

原版頁面

圖、程式碼、公式、版面都在原位，技術書照樣讀。

點字就查

意思跳在字旁邊，不離開頁面。內建離線詞典，查 ran 會告訴你原形是 run。

畫線與筆記

選一段字就能畫線、寫一句話。整本的筆記列在旁邊，點了跳回原處。

中英對照

右邊顯示目前這一頁的中文，跟著翻頁走。也可以只翻選起來的那一段。

生詞本

按星號收起來，連當時那一句、哪本書、第幾頁一起記。

拖進來就開

直接開硬碟裡的檔，不用上傳。下次打開接著上次那一頁。

快捷鍵

開書Ctrl + O
上一頁 / 下一頁← →
放大 / 縮小Ctrl + 滾輪
符合寬度Ctrl + 0

掃描版的 PDF（頁面是圖片）點不到字。
